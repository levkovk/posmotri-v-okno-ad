# Посмотри в окно

Проектная работа Яндекс Практикума: CSS для приложения с поиском видео по городу и времени суток.

Репозиторий: https://github.com/levkovk/posmotri-v-okno-ad

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер из каталога проекта:

```sh
python -m http.server 8000
```

Затем откройте http://localhost:8000.

## Реализация

- Фиксированная композиция по макету с центрированием на большом экране.
- Список видеокарточек с прокруткой и ограничением длинных текстов.
- Чекбоксы с псевдоэлементами, состояния наведения, нажатия и клавиатурного фокуса.
- Локальные шрифты Oswald и Fira Sans Condensed.

HTML, скрипт приложения, прелоадеры и заглушки ошибок сохранены из официальной заготовки:
https://github.com/yandex-praktikum/posmotri-v-okno-ad

Для загрузки видео требуется доступ к учебному API `v-content.practicum-team.ru`.
